# Chía Mora — Energía natural en cada cucharada

Sitio web informativo para el proyecto estudiantil **Chía Mora**, una propuesta de chía con frutas naturales.

## Contenido del sitio

- Página de presentación del producto.
- Secciones informativas sobre beneficios, ingredientes, preparación y presentaciones.
- Menú desplegable con ventanas informativas: quiénes somos, catálogo, pasos de preparación, información nutricional aproximada, QR y contacto.
- Diseño adaptable a móviles y computadoras.
- Tema claro/oscuro según la preferencia del sistema.
- Estilos y JavaScript incluidos directamente en `index.html`; no requiere un proceso de compilación.

## Archivos

- `index.html`: página principal completa del sitio.

## Cómo abrirlo

1. Descarga o descomprime la carpeta del proyecto.
2. Abre `index.html` con un navegador moderno (Chrome, Firefox, Edge, etc.).

También puedes publicarlo en un servicio de alojamiento estático que admita archivos HTML.

## Dependencias externas

- Google Fonts para las tipografías **Fraunces** y **Work Sans**. Se necesita conexión a internet para cargarlas; el sitio conserva fuentes alternativas si no están disponibles.
- La imagen del catálogo está incrustada en el propio HTML como datos Base64.

## Personalización

Abre `index.html` en un editor de texto o código. Los estilos están dentro de la etiqueta `<style>` y las interacciones del menú y las ventanas están dentro de `<script>`.

## Nota

La página indica que la información nutricional es aproximada y se presenta con fines educativos, como parte de un emprendimiento estudiantil.
